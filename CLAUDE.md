# Project instructions for Claude Code

Read `docs/EXPERIMENTS_LANGUAGE_INTERFACE.md` first, then the reused spec `docs/source_EXPERIMENTS.md` for the pipeline conventions.

Rules: fixed seeds, resumable stages, `pytest` before committing, ask the author before changing models, languages, dialects, thresholds or sample sizes. No em dashes in text for the author or paper. Raw outputs for harmful prompts stay local. Keep the repository private (double-blind review); no author-identifying text in artifacts.
